# MVP 冻结功能清单

香农之翼第一阶段不是删除旧功能，而是冻结暂不需要的功能。

**冻结含义：**
- 源码保留
- 数据库表保留
- 后端模块保留
- 管理端菜单/小程序入口隐藏
- 后续如商家需要，可通过菜单、入口、配置开关恢复

**重要：**
- 冻结不是废弃
- 冻结不是删除
- 冻结功能不能在没有评审的情况下物理删除

## 功能总表

| 功能 | 当前状态 | 冻结原因 | 保留原因 | 当前处理方式 | 未来恢复方式 | 风险备注 |
|------|----------|----------|----------|--------------|--------------|----------|
| 积分商城 | 冻结 | MVP 不需要积分兑换链路 | 未来可能做会员积分营销 | 隐藏管理端/小程序入口，后端模块保留 | 恢复菜单和小程序入口，联调积分接口 | 积分可能关联订单、用户等级 |
| 余额/充值/账单 | 冻结 | MVP 优先微信/模拟支付 | 未来商家可能做储值活动 | 隐藏余额支付、充值、账单入口 | 打开入口，确认支付和余额扣减链路 | 余额涉及资金，恢复需完整测试 |
| 会员卡 | 冻结 | MVP 不做会员等级和卡权益 | 未来会员运营可能需要 | 隐藏入口，保留用户/会员底层能力 | 恢复入口，联调会员权益 | 会员可能关联积分、折扣 |
| 微信公众号 | 冻结 | MVP 不依赖公众号运营 | 未来可用于消息通知和运营 | 隐藏管理端菜单，不配置公众号 | 配置公众号参数，恢复菜单和消息模板 | 需要公众号认证和配置 |
| 快递物流 | 冻结 | 无人机配送不走传统快递 | 未来可能用于补充配送方式 | 隐藏菜单，保留模块 | 恢复菜单，确认物流接口配置 | 物流接口可能需要重新申请 |
| 收银台/扫码枪/扫码盒子 | 冻结 | MVP 不做线下收银 | 未来线下店可能需要 | 隐藏入口，不配置设备 | 恢复入口，配置收款设备 | 需要硬件采购和配置 |
| 桌台点餐/扫码点餐 | 冻结 | MVP 不做桌面点餐 | 未来店内场景可能需要 | 隐藏入口，不传 orderType=desk | 恢复入口，联调桌台订单 | 桌台可能关联打印、叫号 |
| 多门店/店铺切换 | 冻结为单店模式 | MVP 先跑 DC 香农咖啡单点 | 商品、订单、优惠券依赖 shopId/storeId | 保留默认站点/店铺，隐藏切换入口 | 打开站点/门店入口，确认多店数据隔离 | 多店涉及数据隔离和权限 |
| 多租户/SaaS 入口 | 冻结为单租户模式 | MVP 不做 SaaS 平台运营 | 底层权限/数据隔离可能依赖 tenant | 隐藏租户管理入口，tenant 底层保留 | 恢复租户菜单，重新验证租户隔离 | 租户隔离涉及权限和数据安全 |
| 云小票打印 | 冻结 | MVP 不配置打印机 | 未来线下制餐可能需要 | 不配置打印机，必要时用配置开关关闭 | 配置打印机，恢复打印流程 | 需要打印机硬件和云打印服务 |
| 代码生成器/监控/Druid/Redis/定时任务 | 仅开发负责人可见 | 演示和普通管理不需要 | 开发排查、维护可能需要 | 隐藏普通入口，保留代码 | 负责人按需打开 | 需要权限控制 |

## 冻结功能处理方式

### 管理端

- 通过 `system_menu.visible=false` 隐藏菜单
- 不删除菜单记录
- 不修改 `deleted` 字段
- 不删除 Vue 页面

### 小程序端

- 通过入口隐藏或 feature 开关隐藏
- 不删除页面
- 不删除 `pages`/`subpages` 下冻结页面

### 后端

- 保留模块
- 保留 Controller/Service/Mapper
- 保留数据库表
- 不从 `pom.xml` 中移除模块

### 数据库

- 不 drop 表
- 不 delete 菜单
- 不清空业务表
- SQL 默认不提交，因为 `.gitignore` 忽略 `*.sql`

## 恢复功能前检查清单

恢复某个冻结功能前，必须检查：

1. 管理端菜单是否存在
2. 管理端页面是否还能打开
3. 小程序入口是否存在
4. 后端接口是否可用
5. 数据库表是否完整
6. 权限编码是否还在
7. 是否依赖默认店铺/租户
8. 是否影响订单/支付/用户主链路
9. 是否需要补配置项
10. 是否需要测试数据

## 禁止事项

在没有单独评审前禁止：

- 删除 `score`/`mp`/`express`/`pay`/`member`/`system`/`tenant` 等模块
- 删除数据库表
- 删除菜单记录
- 删除冻结页面
- 删除冻结 API
- 把 `shopId`/`storeId` 机械改成 `siteId`
- 把无人机状态塞进订单表
- 把冻结功能当成废弃功能处理
