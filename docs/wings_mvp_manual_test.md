# Wings of Xiangnong MVP 手动测试流程

> 适用阶段：源码清理基本收束后，用于确认现有点餐系统、管理端、配送展示与小程序主链路是否可用。  
> 测试原则：只测 MVP 主链路，不陷入旧系统所有功能。冻结模块只确认“不影响主链路”，不做完整验收。

---

## 0. 测试目标

本轮测试回答五个问题：

1. 后端能否正常启动并提供接口；
2. 管理端能否正常登录和打开核心页面；
3. 商品、站点、订单这些已有基础能力是否可用；
4. delivery 配送看板是否能正常展示 mock 数据；
5. 小程序能否完成从浏览商品到提交订单的主链路。

本轮不要求完整验证：

- 积分商城；
- 优惠券营销；
- 公众号管理；
- 支付商户配置；
- 短信、邮件、社交登录；
- 代码生成；
- 工作流；
- 复杂权限配置；
- UEditor 全功能；
- 所有后台系统管理功能。

这些属于冻结或低优先级模块。

## 1. 测试前准备

### 1.1 环境准备

确认以下服务可用：

- [ ] MySQL 已启动；
- [ ] Redis 已启动；
- [ ] 后端配置中的数据库连接正确；
- [ ] 后端配置中的 Redis 连接正确；
- [ ] 管理端依赖已安装；
- [ ] 小程序开发工具或 HBuilderX 可打开项目。

### 1.2 数据准备

至少准备以下数据：

| 数据类型 | 要求 |
| --- | --- |
| 管理员账号 | 能登录 admin 管理端 |
| 商品分类 | 至少 1 个启用分类 |
| 商品 | 至少 1 个上架商品 |
| 商品规格 | 如果系统要求规格，则至少配置 1 个可售规格 |
| 站点/门店 | 至少 1 个可用站点 |
| 用户账号 | 小程序侧可登录或可进入下单流程 |
| 收货地址/配送点 | 至少 1 个可选地址或校园配送点 |

如果某些数据还没有，就在管理端补齐。

## 2. 启动测试

### 2.1 启动后端

在后端目录启动服务。

示例：

```powershell
cd F:\projects\Wings-of-Xiangnong\backend
mvn -pl server -am spring-boot:run -Dspring-boot.run.profiles=local
```

如果 local 不可用，再试：

```powershell
mvn -pl server -am spring-boot:run -Dspring-boot.run.profiles=dev
```

启动成功标准：

- [ ] 控制台出现 `Started ...Application`；
- [ ] 控制台出现 Tomcat 启动端口；
- [ ] 没有数据库连接失败；
- [ ] 没有 Redis 连接失败；
- [ ] 没有端口占用错误。

记录：

```text
后端端口：
启动 profile：
是否成功：
失败日志摘要：
```

### 2.2 启动管理端

```powershell
cd F:\projects\Wings-of-Xiangnong\admin
pnpm dev
```

启动成功标准：

- [ ] 出现 `VITE ready`；
- [ ] 出现本地访问地址，例如 `http://localhost:80/` 或 `http://localhost:5173/`；
- [ ] 没有 `ERROR`；
- [ ] 浏览器能打开登录页。

允许存在以下 warning：

- Vite CJS deprecated；
- Sass `@import` deprecated；
- Sass legacy-js-api deprecated；
- UnoCSS entry warning。

这些不是当前阻塞项。

记录：

```text
管理端端口：
是否能打开登录页：
是否白屏：
浏览器 Console 红色错误：
```

### 2.3 启动小程序

使用 HBuilderX 或微信开发者工具打开：

```text
miniapp/
```

启动成功标准：

- [ ] 小程序首页能打开；
- [ ] 页面没有持续白屏；
- [ ] 控制台没有持续红色报错；
- [ ] 能请求后端 app-api 或 mock 数据。

记录：

```text
运行平台：
是否能打开首页：
是否能访问后端：

```

## 11. 冻结模块检查

以下模块不做完整测试，只确认它们不影响主链路：

| 模块 | 检查方式 | 通过标准 |
| --- | --- | --- |
| 积分商城 | 不主动进入，若菜单隐藏则通过 | 不影响点餐和配送 |

| 系统短信/邮件 | 跳过 | 不影响登录和下单 |
| UEditor | 只在商品编辑富文本处简单打开 | 不导致页面崩溃 |

记录：

```text

是否影响主链路：

```
